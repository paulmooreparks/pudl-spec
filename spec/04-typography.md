# 4. Typography

Status: not yet written.

This chapter will set out the three faces and their roles, the type scale's use for each kind of text, the heading levels, weights, line heights and tabular figures.

The rules it will state are already in force in the web implementation. Body text uses a legible sans-serif interface face. Identifiers, versions, timestamps and other machine values use a monospace face. The display face for headings and the application's name may be any legible face, serif included. Weights stay between 400 and 700. Figures are tabular where numbers are data.
