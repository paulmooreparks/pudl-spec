# 9. Applets

Status: not yet written.

An applet is interactive content, such as a game, a calculator or an editor, that runs unchanged in a page of its own, embedded in a document, or inside a window. This chapter will state the contract between an applet and whichever host it lands in, independently of the web: how the host tells the applet what kind of space it has, how the applet hands its state to the host to keep, how a host hands state back, how applets serve requests from one another without naming each other, and how an applet offers commands to its window's menu.

The web implementation's applet runtime is the working model, and its README describes it.
